# Database

## Source of Truth

Not applicable. Umbra has no database, schema, migrations, connection configuration, or data-access layer.

## Data Model

Not applicable. The package defines UI component props and types but no persisted domain entities.

## Relationships and Derived Data

Not applicable. Umbra has no persisted relationships, indexes, caches, or computed domain data.

## Data Lifecycle

Not applicable. The package does not create, update, import, export, archive, or delete domain records.

## Migrations, Seeding, and Imports

Not applicable. There are no migrations, seeds, database reset operations, or data import paths.

## Data Safety

There is no production database or domain data in this repository. The theme's `localStorage` value and sidebar preference cookie are disposable UI preferences, not application records. Data safety for consumer applications remains owned by those repositories.
